# מחולל קישורים לאוצריא

תוכנת Windows ליצירת קישורים בין פירושים לספרי הבסיס שלהם, לפי **מבנה הכותרות** של הספר (דף בגמרא, פרק בתנ"ך, סימן בשולחן ערוך, פרק והלכה בפסקי הרא"ש ועוד). הקישורים מאומתים מול תוכן העניינים של אוצריא (`seforim.db`) ונכתבים בפורמט הייבוא של הספרייה האישית.

אפשר להגדיר כללי כותרות בעצמך, או לתת לבינה מלאכותית (Claude, Gemini או OpenAI) לסרוק את מבנה הספר ולהציע את הכללים. **ה-AI אופציונלי.** בלעדיו התוכנה עובדת עם כללים מוכנים וכללים אישיים.

## התקנה

הורד את `OtzariaLinker.exe` מ-[Releases](../../releases/latest). זה קובץ בודד, בלי התקנת Python ובלי התקנה. כל שינוי בקוד בונה Release חדש אוטומטית. צריך את אוצריא מותקנת במחשב, כי התוכנה קוראת (לקריאה בלבד) את `seforim.db`.

## שימוש

### יצירת קישורים לספר
1. **בחר קבצים**: קובץ הספר (txt בפורמט אוצריא), או כמה קבצים שחולקים אותם כללים.
2. **ספר יעד**: הספר שהפירוש מקושר אליו (חיפוש לפי הקלדה מתוך רשימת הספרים של אוצריא). בגמרא אפשר לסמן "המסכת נקבעת משם הקובץ".
3. **כללי כותרות**: בחר מערך מוכן, או לחץ **ערוך כללים** להגדרה אישית (סוג כלל, רמת כותרת, ביטוי רגולרי, ותבנית המיקום). אפשר לשמור כפרופיל לשימוש חוזר.
4. **סרוק מבנה בעזרת בינה מלאכותית**: שולח למודל תקציר של הכותרות (ובאישורך גם כמה שורות לדוגמה), מקבל כללים מוצעים, בודק אותם בהרצה יבשה ומציג את אחוז הכיסוי. אפשר לתת משוב ולנסות שוב.
5. **תצוגה מקדימה**, ואז **שמור קובץ קישורים**. מייבאים באוצריא: הגדרות, ספרים אישיים, ייבוא קישורים.

### בדיקה ותיקון קישורים קיימים
בחר את תיקיית הספרים ואת תיקיית קבצי הקישורים (מבנה המאגר של Otzarya-Unofficial-Books: `קישורים/NN/links.csv`). התוכנה משווה כל קבוצת קישורים לספר הנוכחי, מזהה הזזות של שורות (למשל כשנוספה שורת תמונה בראש הספר), ומתקנת. לפני הכתיבה נשמר גיבוי zip. ספרים שיש להם כלל יצירה ואין להם קישורים מקבלים קישורים חדשים.

### יצירה אוטומטית לכל המאגר (שורת פקודה, בלי ממשק)

```
python -X utf8 auto_links.py <תיקיית ספרים> <seforim.db>
```

הסקריפט `auto_links.py` עובר על כל הספרים בתיקייה ויוצר להם קישורים בלי כל התערבות, ל-`קבצי קישורים וסדר הדורות/קישורים/auto/links.csv`. הוא משמש את ה-workflow של [MyLibraryforOtzaria](https://github.com/Tzadikvtovlo/MyLibraryforOtzaria), שבונה DB אישי לאוצריא ישירות בגיטהאב. בשלב אחד רצים הכללים המובנים (בבלי, ירושלמי שקלים, תנ"ך, הגהות אשרי, ספרי הלכה מוגדרים). בשלב שני, לכל ספר אחר, הסקריפט מנסה לזהות מתוך **שם הקובץ** על איזה ספר הוא מפרש (למשל `...על שולחן ערוך אורח חיים`), בוחר את כלל הכותרות שמתאים למבנה ספר היעד, ורושם קישורים רק אם לפחות חצי משורות הספר קושרו למקום קיים.

**זה זיהוי כללי ולא תמיד מדויק:** הוא מנחש לפי השם, ויכול לטעות או לא לזהות. הקישורים מאומתים מול `seforim.db`, אבל זה לא מבטיח שהיעד הוא מה שהתכוונת אליו. ספרים שכבר יש להם קישורים לא נוגעים בהם. בסוף הריצה מודפס לכל ספר אם קושר ולמה לא.

## הגדרות ומפתח API

בלחיצה על **הגדרות**: בחירת ספק, הדבקת מפתח, בחירת מסלול (ב-Gemini: חינמי או בתשלום), **בדוק מפתח ורענן מודלים** ובחירת מודל. הכפתור **איך יוצרים מפתח?** פותח מדריך מפורט בדפדפן, ולכל ספק קישור ישיר לדף יצירת המפתח.

| ספק | מסלול | הערות |
|---|---|---|
| Gemini (Google) | חינמי עם מגבלת בקשות לדקה (התוכנה מאטה לבד), או בתשלום | המסלול החינמי עשוי להשתמש בתוכן שנשלח לשיפור המוצר |
| Claude (Anthropic) | בתשלום לפי שימוש | מנוי Claude לא כולל API |
| OpenAI | בתשלום לפי שימוש | מנוי ChatGPT לא כולל API |

**פרטיות:** הספרים עצמם לא נשלחים. נשלח רק תקציר כותרות, ורק אם בחרת במפורש גם שורות דוגמה. המפתח נשמר בקובץ מקומי (`%APPDATA%\OtzariaLinker\config.json`) בלי הצפנה.

## מה שונה מהכלים הקיימים בפורום

| כלי | מה הוא עושה | מה שונה |
|---|---|---|
| [Link-Notes](https://github.com/Otzaria/Link-Notes) | מקשר ספר לקובץ הערות לפי מספרי הפניה מסומנים | קישור הערות לפי מספרים, לא לפי מבנה כותרות. פלט `_links.json` |
| [Otzaria Link Generator](https://github.com/crfh1672/otzaria-link-generator) | מזהה מראי מקומות וראשי תיבות בתוך הטקסט | זיהוי ציטוטים בתוך הטקסט, לא לפי כותרות. דורש Node.js |

התוכנה הזו קושרת פירוש לספר בסיס לפי כותרות, מאמתת מול תוכן העניינים הרשמי, מתמודדת עם שמות כפולים בתיקיות שונות, ומתקנת קישורים קיימים אחרי שינוי בספרים.

## פורמט הפלט

קובץ CSV (UTF-8 עם BOM, שורות CRLF) בעמודות: `מקור, ספר_מקור, מקור_אישי, ספר_יעד, מיקום_יעד, סוג, יעד_אישי, קטגוריית_מקור`. `מקור` הוא מספר השורה בקובץ הספר (שורה ראשונה = 1). שורות כותרת, שורות ריקות והשורה הראשונה בקובץ אינן מקושרות.

## מגבלות
- ספרים שאין בהם מיקום מפורש ביעד (שיעורים לפי נושא, שו"ת, מחשבה) אי אפשר לקשר אוטומטית.
- בדיקת הכללים הבנויים מראש נעשתה על מאגר הספרים של Otzarya-Unofficial-Books: המנוע משחזר את כל 938 קבוצות הקישורים הקיימות בדיוק. סריקת ה-AI נבדקה עם תשובות מדומות בלבד, ולא מול ספקים אמיתיים.
- בממשק של Tk ב-Windows טקסט עברי שמכיל אנגלית עלול להיראות בסדר שגוי במקומות בודדים.
